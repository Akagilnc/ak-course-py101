L5 讲了 DataFrame 和图，L6 讲了排序和筛选。L7 正式引入时间序列里很关键的一步：用昨天的数据和今天的数据做比较。这里可以继续用疫情数据，也可以换成股票数据；如果现场想要更有吸引力，后半可以更多讲股票。

- 输出：`l7_change_report.xlsx`。
- 课堂重点：累计数看规模，新增数看速度；很多判断要看变化，而不是只看总量。

make_daily_change_report(file_name)

目标：

- 计算每日新增。

### 阶段 1：整理历史数据

备课代码：

```python
import json
import pandas as pd


def make_daily_change_report(file_name):
    file = open(file_name, encoding="utf-8")
    raw_data = json.load(file)
    file.close()

    history = raw_data["data"]["otherhistorylist"]

    df = pd.DataFrame(
        history,
        columns=["date", "certain"],
    )

    df = df.rename(columns={
        "date": "日期",
        "certain": "累计确诊",
    })

    df = df.astype({"累计确诊": int})

    print(df.head())
```

### 阶段 1 Recap

- L7 的第一段基本复用 L5。
- 这次只保留日期和累计确诊，减少干扰。
- 真正的新内容在下一步：用昨天的数据计算今天的变化。

### 阶段 2：计算每日新增

备课代码继续写：

```python
    df["昨日确诊"] = df["累计确诊"].shift(1)
    df["新增确诊"] = df["累计确诊"] - df["昨日确诊"]

    df.to_excel("l7_change_report.xlsx", index=False)
```

最后调用：

```python
make_daily_change_report("lesson4.json")
```

### 阶段 2 Recap

- `shift(1)`：把一列整体往下挪一格。
- 往下挪以后，每一行旁边就有了昨天的数据。
- 今天累计减昨天累计，就是今天新增。
- 第一行没有昨天，所以会出现空值。

## 案例 1：累计数还在涨，变化速度怎么看

### 目标

理解累计数和新增数的区别。这个概念比 `shift` 语法更重要。

### 轻代码

```python
df["新增确诊"] = df["累计确诊"] - df["昨日确诊"]
```

只解释一句：用今天的累计减昨天的累计，得到今天新增。

### 问题

- 累计确诊会不会轻易下降？
- 如果新增确诊从 20 万降到 10 万，累计确诊还会不会继续上升？
- 只看累计图，会不会错过变化速度？

### 所以呢

- 累计数适合看规模，新增数适合看速度。
- 销售额、粉丝数、投诉量也一样：累计数字还在变大，不代表今天的增长没有变慢。
- 如果每日新增连续下降，说明变化速度已经先转向了；累计总数通常会晚一步才显得“没那么糟”。
- 所以 L7 真正学的是：把今天和昨天放在一起，才能看出变化正在加速还是减速。

### AI 可选

AI 输入页：

> 请用“账户余额”的类比解释：为什么总金额还在增加，但每天新增的钱变少了。

参考输出页：

```text
总金额就像账户余额，只要每天还有钱进来，它就会继续增加。
但是每天新增的钱变少，说明增加速度已经放慢。

所以“总金额还在增加”和“每天新增变少”不矛盾。
前者看总量，后者看速度。
```

检查重点：

- 要说清楚“总量”和“增量”不同。
- 回答要分清“总量”和“新增速度”，先把指标说准。

## 案例 2：找新增最高的一天

### 目标

新增最高的一天，是最值得回头看的异常日之一。

### 轻代码

```python
top_day = df.sort_values(by="新增确诊", ascending=False).head(1)
```

只解释一句：按新增确诊从大到小排序，取第一行。

### 问题

- 新增最高的一天，为什么比累计最高的一天更值得看？
- 如果新增最高的一天刚好出现在统计口径调整后，能不能直接说那天疫情最严重？
- 找到异常日以后，下一步应该查什么？

### 所以呢

- 新增最高的一天不是答案，而是线索。
- 数据突然变大，可能是真实变化，也可能是补录、延迟上报、统计口径调整。
- 找到异常日以后，下一步不是立刻写结论，而是先查数据来源：这一天有没有口径变化？有没有集中补报？有没有节假日影响？
- 异常值最有价值的地方，是提醒我们继续追问，而不是帮我们省掉判断。

### AI 可选

AI 输入页要包含这一天的数据，不只写“新增最高”。

```text
日期          累计确诊      昨日累计确诊    新增确诊
2020-10-05    35270206      35151050       119156
```

> 请帮我列出三个可能原因，解释为什么某一天新增确诊突然升高。用“可能”来表达，不直接下结论。

参考输出页：

```text
某一天新增确诊突然升高，可能有几类原因：
1. 真实传播速度变快。
2. 前几天的数据延迟上报，集中补录到这一天。
3. 检测范围扩大，发现了更多病例。
4. 统计口径发生变化。

仅凭这一行数据，还不能判断是哪一种原因。
```

检查重点：

- 可以列“真实传播加快、统计补录、检测增加、口径变化”等可能性。
- 政策原因需要单独证据支持。

## 案例 3：最大回撤，收益之外的痛感

### 目标

引入一个成人会觉得有用的概念：最大回撤。

这部分可以换成股票例子。重点是理解“最终赚了”和“中途能不能扛住”不是一回事，代码只看概念。

### 场景

两只股票：

```text
股票A：最终收益 20%，中途最大下跌 8%
股票B：最终收益 35%，中途最大下跌 40%
```

只看最终收益：

- 股票B 更好。

看最大回撤：

- 股票B 中途非常难拿住。

### 轻代码

只看大意：

```python
peak = price.cummax()
drawdown = (price - peak) / peak * 100
max_drawdown = drawdown.min()
```

一句话解释：一路记录曾经到过的最高点，再看从最高点跌下来最多跌了多少。

### 问题

- 如果你真的拿着钱，股票B 中途跌 40% 时还能不能坚持？
- 为什么回测只看最终收益会骗人？
- 你更愿意选收益高但过程吓人，还是收益低一点但过程稳一点？

### 所以呢

- 收益率回答“最后赚了多少”，最大回撤回答“中途最难的时候跌到哪里”。
- 两个产品最后都赚钱，但一个中途只跌 5%，另一个中途跌 40%，真实体验完全不同。
- 对普通人来说，过程不是小事。中途跌太深，很多人等不到最后收益出现，就已经离场了。
- 所以看投资数据不能只看终点，还要看路上最难熬的那一段。

### AI 可选

AI 输入页：

```text
股票A：最终收益 20%，中途最大下跌 8%
股票B：最终收益 35%，中途最大下跌 40%
```

> 请用普通人听得懂的话解释最大回撤。只解释这个指标在提醒什么。

参考输出页：

```text
最大回撤提醒的是：从曾经最高点往下跌，最难受的时候跌了多少。

股票B 最后收益更高，但中途曾经跌 40%，很多人可能拿不住。
股票A 最后收益低一些，但过程更稳。

所以最大回撤不是看最后赚多少，而是看中途要承受多大的下跌。
```

检查重点：

- 可以用“坐过山车”“中途最大跌幅”类比。
- 重点放在“过程里的最大下跌”，不延伸到买卖判断。

## 后半 Recap

- `shift` 让我们把“今天”和“昨天”放在同一行比较。
- 累计数看规模，新增数看速度。
- 排序可以找到异常日，但异常日需要解释。
- 最大回撤提醒我们：最终结果之外，过程也很重要。
