# L6

## 定位

L6 的主题：用 pandas 在一张大表里排序、筛选、找重点。

L5 已经完成第一次 pandas 报告：从 JSON 到 DataFrame，整理列，计算一列，导出 Excel 和图。L6 不急着多表合并，先让学生在一张更大的表里理解 pandas 的第二个价值：不用人工翻表，可以快速找出最值得看的行。

- 输入：疫情国家/地区数据，或老师准备好的股票/地区大表。
- 处理：保留关键列，转换数字，排序，取 Top N，简单条件筛选。
- 输出：`l6_rank_report.xlsx`。
- 课堂重点：排序和筛选不是炫技，而是从大量数据里先找重点。

## 前半：生成疫情排名表

### 章节页

`#1 从大表里找重点`

Sort and filter a DataFrame.

### 主任务

函数名：

```python
make_country_rank_report(file_name)
```

输入：

- 一份疫情 JSON 数据。

输出：

- `l6_rank_report.xlsx`
- `l6_multi_rank_report.xlsx`

目标：

- 把国家/地区数据整理成表。
- 计算死亡率和治愈率。
- 按累计确诊排序，导出完整排名表。

### 数据页：国家/地区数据长什么样

每一行大概是一个国家或地区：

```python
{
    "name": "美国",
    "conNum": "7602935",
    "econNum": "2550339",
    "cureNum": "4840096",
    "deathNum": "212500"
}
```

这行数据可以读成：

- `name`：国家/地区。
- `conNum`：累计确诊。
- `econNum`：现存确诊。
- `cureNum`：累计治愈。
- `deathNum`：累计死亡。

### 阶段 1 目标

- 从 JSON 里找到所有国家/地区记录。
- 只保留名称、累计确诊、现存确诊、治愈、死亡这几列。
- 把表头改成中文，把数字转成真正能计算的类型。

### 阶段 1：整理成 DataFrame

备课代码：

```python
import json
import pandas as pd


def make_country_rank_report(file_name):
    file = open(file_name, encoding="utf-8")
    raw_data = json.load(file)
    file.close()

    countries = raw_data["data"]["otherlist"]

    df = pd.DataFrame(
        countries,
        columns=["name", "conNum", "econNum", "cureNum", "deathNum"],
    )

    df = df.rename(columns={
        "name": "国家/地区",
        "conNum": "累计确诊",
        "econNum": "现存确诊",
        "cureNum": "累计治愈",
        "deathNum": "累计死亡",
    })

    df = df.astype({
        "累计确诊": int,
        "现存确诊": int,
        "累计治愈": int,
        "累计死亡": int,
    })

    print(df.head())
```

这段代码可以在 IDE 里现场写。HTML 不单独放前半代码页。

### 阶段 1 Recap

- `DataFrame`：把一批字典记录整理成表格。
- `columns`：创建表格时，只选择这一步需要的几列。
- `rename`：把英文字段名改成更容易读的中文列名。
- `astype`：把文本形式的数字转成真正能计算的数字。

### 阶段 2 目标

- 新增死亡率、治愈率，把绝对数换成比例。
- 按累计确诊从大到小排序，得到完整排名表。
- 导出 Excel，下一阶段再把它读回来继续处理。

### 阶段 2：计算指标，排序导出

备课代码继续写在同一个函数里：

```python
    df["死亡率"] = (df["累计死亡"] / df["累计确诊"] * 100).round(2)
    df["治愈率"] = (df["累计治愈"] / df["累计确诊"] * 100).round(2)

    df = df.sort_values(by="累计确诊", ascending=False)

    df.to_excel("l6_rank_report.xlsx", index=False)
```

### 阶段 2 Recap

- `sort_values()`：按某一列排序。
- `ascending=False`：从大到小。
- 导出的 Excel 不是结束，而是下一步分析的输入。
- 排序不是结论，只是把值得先看的数据放到前面。

### 阶段 3 目标

- 找到“有压力”的地区。
- 先把阶段 2 生成的 Excel 重新读回来。
- 压力有不同解释：当前压力、死亡压力、恢复压力。
- 同一个 Excel 文件里，分别保存到不同 sheet。

### 阶段 3：多角度排序并导出多 sheet

备课代码继续写在同一个函数里：

```python
    rank_df = pd.read_excel("l6_rank_report.xlsx")

    active_top = rank_df.sort_values(by="现存确诊", ascending=False).head(20)
    death_top = rank_df.sort_values(by="死亡率", ascending=False).head(20)
    low_cure = rank_df.sort_values(by="治愈率", ascending=True).head(20)

    with pd.ExcelWriter("l6_multi_rank_report.xlsx") as writer:
        active_top.to_excel(writer, sheet_name="现存确诊榜", index=False)
        death_top.to_excel(writer, sheet_name="死亡率榜", index=False)
        low_cure.to_excel(writer, sheet_name="治愈率低榜", index=False)
```

最后调用：

```python
make_country_rank_report("lesson4.json")
```

### 阶段 3 Recap

- `read_excel`：把上一阶段导出的 Excel 重新读成 DataFrame。
- `sort_values`：换不同列排序，就会得到不同重点名单。
- `ascending`：`False` 从大到小，`True` 从小到大。
- `sheet_name`：同一个 Excel 文件里，可以保存到不同 sheet。

## 后半：排名表应该怎么读

### 后半章节页

`#2 排名不是答案，只是入口`

前半得到了一张排名表。后半问三个问题：

- 排名第一说明什么？
- 哪个指标更适合比较严重程度？
- 筛选条件会不会改变我们看到的结论？

## 案例 1：第一名说明了什么？

### 目标

排序能帮我们从很多行里找重点，但排名本身不等于完整结论。排名适合快速定位“大数”，但它通常只是下一步调查的入口。

### 轻代码

```python
top20 = df.sort_values(by="累计确诊", ascending=False).head(20)
```

只解释一句：按累计确诊从大到小排序，取前 20 行。

### 展示数据

```text
排名      地区        累计确诊      人口        每百万人确诊
1         大国A       7600000      330000000   23030
2         大国B       4900000      210000000   23333
未进前列  小地区C     120000       1000000     120000
```

### 问题

- 累计确诊第一，至少说明什么？
- 如果两个地区人口规模差很多，只看累计确诊会漏掉什么？
- 看到排行榜第一名以后，下一步应该补哪类信息？

### 所以呢

- Top N 的作用是先把注意力拉到最前面几行，不是直接给结论。
- 按累计确诊排序，大国更容易排在前面。
- 如果人口规模不同，只看累计数就容易忽略比例压力。
- 排名第一只说明“按这个指标，它排第一”。下一步要追问：这个指标有没有被人口、时间范围、统计口径影响。

### AI 可选

AI 输入页要自包含：放一小段 Top 排名表，再放问题。

```text
按累计确诊排序：
地区       累计确诊      人口        每百万人确诊
大国A      7600000     330000000   23030
大国B      4900000     210000000   23333
小地区C    120000      1000000     120000
```

> 请解释这张排序表。先说明按累计确诊排序能看到什么，再说明为什么还要看人口比例。

参考输出页：

```text
这张表先按累计确诊排序，所以大国 A 排在最前面。
这说明它的累计确诊总量最大。

但如果换成“每百万人确诊”，小地区 C 的比例更高。
所以累计确诊适合看总量，人口比例更适合做规模不同地区之间的比较。

这张表还不能解释原因，也不能直接评价好坏。
```

检查重点：

- 可以说“按累计确诊，大国 A 靠前”。
- 需要指出人口比例会改变观察角度。
- 如果要进一步判断，还要补人口、时间范围、统计口径等材料。

## 案例 2：总量、现存、死亡率、治愈率看的是不同问题

### 目标

同一张表有多列指标。这里重点看：不同指标回答不同问题。

### 数据问题

- `累计确诊`：规模有多大。
- `现存确诊`：现在还有多少没有结束。
- `死亡率`：死亡占确诊的比例。
- `治愈率`：治愈占确诊的比例。

展示数据：

```text
地区  累计确诊  现存确诊  累计死亡  死亡率  治愈率
A     7600000   2550000   212500   2.79%   63.66%
B     4900000   503000    146000   2.98%   86.74%
C     120000    78000     3600     3.00%   32.00%
```

### 问题

- 如果要看“历史规模”，应该看哪列？
- 如果要看“现在压力”，应该看哪列？
- 如果要比较“严重程度”，死亡人数和死亡率哪个更合适？

### 所以呢

- 如果关心历史规模，看 `累计确诊`；如果关心现在压力，看 `现存确诊`。
- 如果比较严重程度，死亡人数和死亡率要分开看。
- 同一张表里没有“万能指标”。先把问题说清楚，才知道该拿哪一列说话。
- 比例指标更适合比较，但小样本也会很跳，所以看到高比例时还要回头看样本规模。
- 样本很小的时候，一个病例的变化就可能让比例跳很多，不能只看百分比吓自己。

### AI 可选

AI 输入页：

```text
指标：
累计确诊、现存确诊、累计死亡、死亡率、治愈率

问题：
1. 历史规模有多大？
2. 当前压力有多大？
3. 不同规模地区之间，哪个死亡比例更高？

请把每个问题对应到最合适的指标，并简单说明理由。
```

参考输出页：

```text
历史规模：看累计确诊。
它表示到目前为止一共记录了多少确诊。

当前压力：看现存确诊。
它更接近现在还没有结束的病例规模。

比较死亡比例：看死亡率。
死亡人数容易受地区规模影响，死亡率更适合做比例比较。
```

检查重点：

- 每个指标要对应一个清楚问题。
- “死亡率高”只能说明这张表里的比例更高，原因需要更多材料。

## 案例 3：筛选条件会改变你看到的世界

### 目标

筛选很有用，但筛选条件会影响结果。这个点比语法本身更重要。

### 原始小表

```text
地区  现存确诊  死亡率
A     2550000   2.79%
B     503000    2.98%
C     260000    1.80%
D     120000    4.20%
E     78000     3.00%
F     35000     5.80%
```

### 轻代码

```python
high_pressure = df[df["现存确诊"] > 100000]
```

只解释一句：筛出现在仍有较多确诊的地区。

### 展示结果

```text
问题                  筛选条件          留下哪些地区
先看当前压力          现存确诊 > 100000  A、B、C、D
资源只够看两个地区    现存确诊 > 500000  A、B
先看比例异常          死亡率 > 5%        F
```

### 问题

- 如果要看“当前压力”，应该用哪条线？
- 如果今天只来得及重点分析两个地区，筛选线应该收紧还是放宽？
- 如果问题从“人数多”换成“比例高”，留下来的对象为什么会变？

### 所以呢

- 筛选条件不是随便写一个数字，而是在回答一个具体问题。
- 问题是“当前压力”时，可以先看现存确诊；如果时间、人手、预算只够看少数对象，线通常要画得更高。
- 问题换成“比例异常”时，筛选列也要跟着换成死亡率。
- 所以筛选真正难的不是代码，而是说清楚：我为什么用这条线看这个问题。

### AI 可选

AI 输入页要同时包含原始数据、筛选条件和筛选结果。

```text
原始数据：
地区  现存确诊  死亡率
A     2550000   2.79%
B     503000    2.98%
C     260000    1.80%
D     120000    4.20%
E     78000     3.00%
F     35000     5.80%

筛选条件一：现存确诊 > 100000，结果：A、B、C、D
筛选条件二：死亡率 > 5%，结果：F
```

> 请解释为什么两个筛选条件会留下不同地区。

参考输出页：

```text
两个筛选条件关注的问题不同。

现存确诊 > 100000，是在找当前病例数量较多、压力较大的地区，
所以留下 A、B、C、D。

死亡率 > 5%，是在找死亡比例较高的地区，
所以留下 F。

同一张表换一个筛选条件，重点对象就会改变。
```

检查重点：

- 允许说“这批数据里现存确诊较高”。
- 未来变化不在这张筛选表的回答范围内。
- 结论要回到筛选条件。

## 后半 Recap

- `sort_values()` 让我们快速看排名。
- `head()` 让我们先看最重要的一小段。
- 条件筛选让我们按问题挑数据。
- 同一份数据，换排序列或筛选线，看到的重点就会变。
