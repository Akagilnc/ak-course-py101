## 前半：生成疫情排名表

### 章节页

`#1 从大表里找重点`

Sort and filter a DataFrame.

### 主任务

函数名：

```python
make_country_rank_report(file_name)
```

输入：

- 一份疫情 JSON 数据。

输出：

- `l6_rank_report.xlsx`

目标：

- 把国家/地区数据整理成表。
- 计算死亡率和治愈率。
- 按累计确诊排序，取前 20 名。

### 数据页：国家/地区数据长什么样

每一行大概是一个国家或地区：

```python
{
    "name": "美国",
    "conNum": "7602935",
    "econNum": "2550339",
    "cureNum": "4840096",
    "deathNum": "212500"
}
```

这行数据可以读成：

- `name`：国家/地区。
- `conNum`：累计确诊。
- `econNum`：现存确诊。
- `cureNum`：累计治愈。
- `deathNum`：累计死亡。

### 阶段 1：整理成 DataFrame

备课代码：

```python
import json
import pandas as pd


def make_country_rank_report(file_name):
    file = open(file_name, encoding="utf-8")
    raw_data = json.load(file)
    file.close()

    countries = raw_data["data"]["otherlist"]

    df = pd.DataFrame(
        countries,
        columns=["name", "conNum", "econNum", "cureNum", "deathNum"],
    )

    df = df.rename(columns={
        "name": "国家/地区",
        "conNum": "累计确诊",
        "econNum": "现存确诊",
        "cureNum": "累计治愈",
        "deathNum": "累计死亡",
    })

    df = df.astype({
        "累计确诊": int,
        "现存确诊": int,
        "累计治愈": int,
        "累计死亡": int,
    })

    print(df.head())
```

这段代码可以在 IDE 里现场写。HTML 不单独放前半代码页。

### 阶段 1 Recap

- L5 的 `DataFrame / rename / astype` 继续复用。
- L6 的数据从“一段历史”换成“一批国家/地区”。
- 数据多了以后，人工看完整张表不现实，需要排序和筛选。

### 阶段 2：计算指标，排序导出

备课代码继续写在同一个函数里：

```python
    df["死亡率"] = (df["累计死亡"] / df["累计确诊"] * 100).round(2)
    df["治愈率"] = (df["累计治愈"] / df["累计确诊"] * 100).round(2)

    top20 = df.sort_values(by="累计确诊", ascending=False).head(20)

    top20.to_excel("l6_rank_report.xlsx", index=False)
```

最后调用：

```python
make_country_rank_report("lesson4.json")
```

### 阶段 2 Recap

- `sort_values()`：按某一列排序。
- `ascending=False`：从大到小。
- `head(20)`：只取前 20 行。
- 排序不是结论，只是把值得先看的数据放到前面。

## 后半：排名表应该怎么读

前半得到了一张排名表。后半问三个问题：

- 哪个指标更适合比较严重程度？

## 案例 1：Top N 排名在回答什么

### 目标

排序能帮我们从很多行里找重点，但排名本身不等于完整结论。

### 轻代码

```python
top20 = df.sort_values(by="累计确诊", ascending=False).head(20)
```

只解释一句：按累计确诊从大到小排序，取前 20 行。

### 问题

- 累计确诊排名靠前，能直接说明这个国家“更危险”吗？
- 如果人口规模差很多，只看累计确诊公平吗？
- 排名更像答案，还是更像下一步调查的入口？

### 所以呢

- Top N 的作用是先把注意力拉到最前面几行，不是直接给结论。
- 按累计确诊排序，人口大、检测多的国家更容易排在前面；这像公司按销售额排名，大公司天然更容易靠前。
- 排名第一只说明“按这个指标，它排第一”。下一步要追问：这个指标有没有被人口、规模、统计口径影响？

### AI 可选

AI 输入页要自包含：放一小段 Top 排名表，再放问题。

```text
国家/地区        累计确诊
美国            81167440
印度            43060086
巴西            30183929
法国            26744303
德国            23116692
```

> 请用普通话解释这张累计确诊排名表。只描述表中能看出的信息，原因部分先留空。

参考输出页：

```text
这张表按累计确诊人数从高到低排列。
从表中可以看到，美国、印度、巴西等国家累计确诊数量靠前。

但这张表只能说明“按累计确诊这个指标，它们排在前面”。
它不能直接说明治理好坏，也不能预测未来变化。
如果要进一步比较，还需要人口规模、检测口径、时间范围等材料。
```

检查重点：

- 可以说“哪些国家累计确诊靠前”。
- “治理好坏”需要更多材料。
- 历史数据回答过去发生了什么，未来预测要另找证据。

## 案例 2：总量、现存、死亡率、治愈率看的是不同问题

### 目标

同一张表有多列指标。这里重点看：不同指标回答不同问题。

### 数据问题

- `累计确诊`：规模有多大。
- `现存确诊`：现在还有多少没有结束。
- `死亡率`：死亡占确诊的比例。
- `治愈率`：治愈占确诊的比例。

### 问题

- 如果要看“历史规模”，应该看哪列？
- 如果要看“现在压力”，应该看哪列？
- 如果要比较“严重程度”，死亡人数和死亡率哪个更合适？
- 如果死亡率很高但累计确诊很少，这个国家应该怎么理解？

### 所以呢

- 如果关心历史规模，看 `累计确诊`；如果关心现在压力，看 `现存确诊`。
- 如果比较严重程度，死亡人数和死亡率要分开看；如果看恢复情况，治愈率才更有用。
- 同一张表里没有“万能指标”。先把问题说清楚，才知道该拿哪一列说话。
- 比例指标更适合比较，但小样本也会很跳，所以看到高比例时还要回头看样本规模。

### AI 可选

AI 输入页：

> 请解释累计确诊、现存确诊、死亡率、治愈率分别适合回答什么问题。每个指标只写一句。

参考输出页：

```text

现存确诊：适合看现在还有多少病例没有结束。
死亡率：适合在确诊规模不同的地区之间比较死亡比例。
治愈率：适合看确诊病例中已经恢复的比例。
```

检查重点：

- 每个指标要对应一个清楚问题。
- “死亡率高”只能说明这张表里的比例更高，原因需要更多材料。

## 案例 3：筛选条件会改变你看到的世界

### 目标

筛选很有用，但筛选条件会影响结果。这个点比语法本身更重要。

### 轻代码

```python
high_pressure = df[df["现存确诊"] > 100000]
```

只解释一句：筛出现在仍有较多确诊的国家/地区。

### 问题

- 如果阈值从 `100000` 改成 `500000`，结果会变多还是变少？
- 如果筛选条件换成 `死亡率 > 5`，看到的国家会不会不同？
- 同一张表，为什么换一个问题就会得到另一批重点对象？

### 所以呢

- 筛选条件就是一条线：线画在 `100000`，会留下这一批；线画在 `500000`，留下的对象会少很多。
- 这条线通常不是数学题，而是现实限制。比如人手、床位、预算有限时，只能先看压力最大的对象。
- 换指标也会换问题：筛 `现存确诊` 是看当前压力，筛 `死亡率` 是看比例风险。
- 所以筛选真正难的不是代码，而是解释清楚：为什么把线画在这里。

### AI 可选

AI 输入页要同时包含筛选条件和筛选结果。

```text
筛选条件：现存确诊 > 100000

国家/地区        现存确诊
美国            745000
德国            410000
法国            260000
```

> 请根据这张筛选表写三句观察，重点放在筛选条件和表格结果之间的关系。

参考输出页：

```text
这张表保留下来的，都是现存确诊超过 100000 的地区。
它说明这些地区在这张表里当前压力较高。
如果把筛选线改成 500000，留下来的地区会明显减少。
```

检查重点：

- 允许说“这批数据里现存确诊较高”。
- 未来变化不在这张筛选表的回答范围内。
- 结论要回到筛选条件。

## 后半 Recap

- `sort_values()` 让我们快速看排名。
- `head()` 让我们先看最重要的一小段。
- 条件筛选让我们按问题挑数据。
- 排名和筛选都不是最终答案，它们只是让我们更快找到值得讨论的对象。
