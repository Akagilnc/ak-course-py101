## 定位

L5 的前半主题：用 pandas 处理一整段历史数据，生成 Excel 和趋势图。

L4 已经把 JSON 文件、dict/list 取值、写 txt、写 Excel 讲过一轮。L5 不再继续只取几个字段，而是把同一份疫情数据整理成一张真正的表：保留需要的列、改成中文列名、把数字文字转成数字、计算一列新指标，再导出 Excel 和趋势图。

- 课堂重点：pandas 不是为了替代前面的 dict/list，而是让“一批数据”的清洗、计算和导出更顺手。

```python
import json
import pandas as pd
import matplotlib.pyplot as plt


def make_history_excel(file_name):
    file = open(file_name, encoding="utf-8")
    raw_data = json.load(file)
    file.close()

    history = raw_data["data"]["otherhistorylist"]

    df = pd.DataFrame(
        history,
        columns=["date", "certain", "die", "recure"],
    )
```

```python
    df = df.rename(columns={
        "date": "日期",
        "certain": "累计确诊",
        "die": "累计死亡",
        "recure": "累计治愈",
    })

    df = df.astype({
        "累计确诊": int,
        "累计死亡": int,
        "累计治愈": int,
    })
```

```python
    df["死亡率"] = (
        df["累计死亡"] / df["累计确诊"] * 100
    ).round(2)

    df.to_excel("l5_report.xlsx", index=False)

    ax = df.plot(x="日期", y="累计确诊", legend=False)
    ax.set_xlabel("date")
    ax.set_ylabel("confirmed")
    plt.savefig("l5_trend.png")
```


```python
make_history_excel("lesson4.json")
```

## 案例 1：Excel 和图分别适合看什么

### 目标

同一份数据有两种交付物：

- Excel：一行一行查具体数字。
- 趋势图：一眼看长期变化。

这不是“哪个更高级”的问题，而是它们回答的问题不同。

### 数据 / 输出

Excel 里可以看到类似这样的明细：

```text
日期      累计确诊      累计死亡      累计治愈      死亡率
10.04   35151050    1034410    26248079    2.94
10.05   35270206    1036359    26340847    2.94
```

趋势图更适合看：

- 累计确诊是否长期上升。
- 上升速度有没有明显变快或变慢。
- 某一段是否出现异常陡峭。

### 问题

- 如果你想查 `10.05` 的死亡率，看 Excel 还是看图？
- 如果你想判断这段时间整体趋势，看 Excel 还是看图？
- 如果这张图发到群里，别人最容易误读什么？

### 所以呢

- Excel 像放大镜：适合查某一天的具体数字，比如 `10.05` 的死亡率是多少。
- 趋势图像望远镜：适合看一段时间整体是在变快、变慢，还是基本平稳。
- 同一份数据，换一种展示方式，回答的问题就变了。交付结果之前，先判断对方是想查一个数字，还是想看整体变化。

## 案例 2：人数更多，风险就一定更高吗？

### 目标

同一组数据，用“人数”看一次，再用“比例”看一次，结论可能会变。

### 数据

假设有两个地区：

```text
地区A：累计确诊 100000，累计死亡 3000，死亡率 3%
地区B：累计确诊 10000，累计死亡 500，死亡率 5%
```

A 的总量更大，B 的比例更高。先别急着说谁“更严重”，要看你在问哪一种严重。

### 轻代码

这里只展示一行，先看它在解决什么问题：

```python
df["死亡率"] = (df["累计死亡"] / df["累计确诊"] * 100).round(2)
```

这行代码的意思：用死亡人数除以确诊人数，得到一个更适合比较的比例。

### 问题

- 如果医院要准备床位和物资，更应该先看死亡人数，还是死亡率？
- 如果想比较两个地区的严重程度，更应该先看死亡人数，还是死亡率？
- 为什么“总量”和“比例”都对，但不能混在一起说？

### 所以呢

- 只看死亡人数，注意力会自然落到大地区，因为它的确诊基数本来就大。
- 死亡率把确诊规模也算进去，能提醒我们：有些地区总人数不大，但比例可能更高，压力不一定更小。
- 绝对数适合看总量，比例适合做比较。两个都要看，但它们回答的不是同一个问题。
- 这和 L1 的股票例子是同一件事：跌了多少钱看损失金额，跌了百分之多少才方便比较严重程度。

### AI 可选


> 请解释为什么比较两个地区时，死亡人数和死亡率要分开看。用买菜涨价或股票涨跌幅做类比。

参考输出页：

```text

死亡率看比例，适合比较不同规模地区的严重程度。

这有点像股票下跌：跌了多少钱看损失金额，
跌了百分之多少才方便比较哪只股票跌得更重。
```

检查重点：

- 类比应该落到“基数不同，比例更适合比较”。
- 回答应该停在“比例比较”，判断范围以题目给出的数据为准。

## 案例 3：累计还在涨，速度可能已经慢了

### 目标

一条往上的线，不一定表示越来越快。先把“总量”和“新增”分开看。

L5 只讲概念，不正式写完整代码。`shift` 留到后面课程再展开。

### 图表冲突

左边一直涨，右边一直降：

- 累计确诊：总量还在增加，曲线自然继续往上。
- 每日新增：每天新增加的人数变少，速度在降。

### 问题

- 只看累计曲线，会不会觉得情况一直在加速变严重？
- 看每日新增柱以后，多看到了什么？
- “越来越多”和“越来越快”是不是一回事？

### 现实类比

总销售额创新高，生意一定更好吗？

```text
日期    累计销售额    当天销售额
周一    10000        10000
周二    16000        6000
周三    19000        3000
周四    20500        1500
```

累计销售额每天都在创新高，但当天生意正在降温。

### 均线

每天的柱子太吵，就看一条更平滑的线。

- 每日新增可能一天高、一天低，看起来很抖。
- 均线就是把最近几天平均一下，让趋势更平滑。
- 股票里的 5 日、10 日均线，和这里看每日新增的思路是一类东西。

### 所以呢

- 累计数：现在一共累积到多少。
- 新增数：今天增加多少，速度有没有变。
- 均线：把短期波动压下去，看趋势方向。
- 一条上升曲线不一定代表情况越来越糟；它可能只是总量还在累积，速度已经放慢。

### AI 可选

AI 输入页：

```text
日期    累计确诊    每日新增
10.01   1000       300
10.02   1260       260
10.03   1480       220
10.04   1660       180
10.05   1800       140
10.06   1900       100

请解释：为什么累计确诊还在上升，但每日新增在下降？
重点说明累计数和每日新增分别在看什么。
```

参考输出页：

```text
这组数据里，累计确诊从 1000 增加到 1900，
所以总量仍然在上升。

但每日新增从 300 降到 100，
说明每天新增加的数量在变少。

所以这不是矛盾：
累计看“总量”，每日新增看“速度”。
总量还在增加，但增加速度已经放慢。
```

检查重点：

- 核心必须落在“累计看总量，新增看速度”。
- 政策、病毒、天气等原因不是这组数据直接给出的信息。
- 可以提均线，但不要把均线说成新的事实来源。
