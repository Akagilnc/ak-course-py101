# Py101 Memory Index

这个目录记录课程改版里的长期经验。它不是某次 session 的总结，而是后续继续改 L1/L2/L3... 时要反复读取和更新的课程记忆。

使用方式：

- 改任何课程 Markdown / HTML 前，先读本文件。
- 如果用户连续纠正同一类问题，把稳定规则沉淀到对应 memory 文件。
- 如果只是一次性的页面调整，不写进 memory。
- 重要规则要写在正文里，不只靠链接。

## Project Memory

- [course-style.md](course-style.md) — 课程内容风格、例子标准、AI 演示标准、投影约束。

## 更新原则

- 记录用户反复强调、跨课时会复用的标准。
- 记录“以后别再犯”的错误类型，而不是只记录最后结果。
- 记录可执行判断标准，例如“说读文件就真读文件”，不要写成抽象口号。
- 新增规则时优先更新已有稳定文件；只有主题明显不同，才新增文件。
