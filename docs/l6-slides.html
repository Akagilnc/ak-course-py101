#1 排序与条件过滤

How to sort and filter a DataFrame?

当数据行数破百时，人眼查阅会失效，需要程序自动定位重点。

数据结构

国家/地区数据长什么样？

{
    "name": "美国",
    "conNum": "7602935",
    "econNum": "2550339",
    "cureNum": "4840096",
    "deathNum": "212500"
}

字段定义

name 国家/地区名称，conNum 累计确诊，econNum 现存确诊，cureNum 累计治愈，deathNum 累计死亡。

挑战

JSON 读出的数字依然是带引号的字符串，必须在 Python 里批量转型以供计算。

阶段 1 Recap

重组大表的三个积木

  • pd.DataFrame(countries, columns=[...]) 把多层嵌套列表变成格式化行列表格。
  • df.rename(columns={...}) 把乱糟糟的原文字段一次性重命名为规范中文。
  • df.astype({...}) 把确诊、死亡、治愈等数字列一键强制转为 int 以供公式运算。
  • df.head() 默认打印大表的前 5 行，适合现场确认表格有没有整理对。

阶段 2 Recap

计算、排序并截取

  • df["死亡率"] = ... 新增死亡率计算列。
  • df.sort_values(by="累计确诊", ascending=False) 按确诊数从大到小对大表进行行重排。
  • .head(20) 过滤丢弃长尾行，只截取前 20 行高热度数据。
  • to_excel(..., index=False) 交付最核心前 20 名报告。

后半

排名不是答案，只是入口

大表整理完了，Top 20 也导出了。后半重点看：排名、指标和筛选条件分别能回答什么问题。

后半路线

大表背后的三个数据分析常识

1. 排名

Top N 很适合抓大数，但它通常只是下一步调查的入口。

2. 指标

排名第一，只说明这个指标排第一

Top N 是粗筛

排行榜会先把数量最大的对象推到前面，但它不能自动解释原因和严重程度。

还要看比例

如果人口规模不同，只看累计数就容易忽略“比例压力”。排名之后，要继续看人口、检测口径和时间范围。

常识落脚点：排名只是粗筛工具。看到第一名之后，下一步是追问这个指标有没有被规模影响。

案例 2 · 讨论

指标服务于具体问题

  • 如果你是医疗总指挥，今晚需要紧急加盖多少病床、调多少医生，你应该看哪个字段？
  • 如果你是新药开发科学家，要向世人证明你的药真能救命，你应该看哪个字段？
  • 如果你是外交舆论发言人，旨在树立国家信心，你更倾向于展示哪一列？

案例 2 · 所以呢

不同问题，选不同指标

总指挥盯“现存”

现存确诊是还没结束的病例，更适合看当前医疗压力。

研发科学家盯“变化”

死亡率适合比较不同规模地区的死亡比例，但原因还需要更多材料。

发言人讲“治愈率”

治愈率适合看恢复情况，但也要结合统计口径和时间范围。

常识落脚点：同一张表没有万能指标。先把问题说清楚，才知道该拿哪一列说话。

案例 3

筛选条件决定了你的世界

条件过滤很有用，但筛选线画在哪里，会影响你看到的结果。

案例 3 · 代码与结果

筛选出仍处于高承载压力的国家

high_pressure = df[df["现存确诊"] > 100000]
国家/地区现存确诊 (床位压力)筛选阈值结果数
美国2550339> 100,000筛出 12 个国家/地区
巴西503289改为 > 500,000只剩 3 个国家/地区

代码只是把阈值改了一下，但留下来的对象会明显变化。

案例 3 · 讨论

阈值线划在哪里？

  • 如果阈值从 10 万改到 50 万，筛出对象大量变少，这仅仅是数学数字的变化吗？
  • 如果支援医疗队只有 5 支，你的代码阈值应该怎么划定？
  • 在公司制定考核指标时，“优秀”的合格线划在哪里，是如何左右员工行为的？

案例 3 · 所以呢

阈值决定你先看哪一批对象

资源有限时

如果人手、床位、预算有限，阈值通常会拉高，先看压力最大的对象。

覆盖面更重要时

如果目标是覆盖更多对象，阈值就会降低，留下来的地区也会更多。

常识落脚点：筛选真正难的不是代码，而是解释清楚为什么把线画在这里。

今晚记住这几句

从排序，到筛选

  • sort_values() 帮我们快速看排名，但排名只是调查入口。
  • head() 帮我们锁定极少数关键大数，但这只是下一步调查的开始。
  • 总量看规模，比例看严重程度，现存看当前压力。
  • 条件筛选语法很简单，但阈值线划在哪里，需要现实理由。
  • AI 可以帮你把表格翻译成人话，但要防止它把“过去排名”说成“未来预测”。
