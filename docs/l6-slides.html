数据多起来以后，人工翻表不是办法。今天让 Python 帮我们排序、截取、筛选。

  • 想知道历史规模，应该先看哪一列？
  • 想知道当前压力，应该先看哪一列？

案例 2 · 所以呢

不同问题，选不同指标

历史规模

累计确诊告诉你到目前为止一共发生过多少。

当前压力

现存确诊是还没结束的病例，更适合看当前医疗压力。

比例比较

死亡率适合比较不同规模地区的死亡比例；样本很小时，一个病例也会让比例跳很多。

同一张表没有万能指标。先把问题说清楚，才知道该拿哪一列说话。

今晚记住这几句

从排序，到筛选

  • sort_values() 帮我们快速看排名，但排名只是调查入口。
  • head() 帮我们锁定极少数关键大数，但这只是下一步调查的开始。
  • 总量看规模，比例看严重程度，现存看当前压力。
  • 条件筛选语法很简单，但阈值线划在哪里，需要现实理由。
  • 同一份数据，换排序列或筛选线，看到的重点就会变。
