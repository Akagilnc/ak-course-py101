# L3

## 定位

L3 的前半主题：从数据到报告，让程序批量生成可读文字。

L2 已经讲过读文本文件，所以 L3 前半先把数据直接写在代码里，让注意力集中在“批量加工数据”和“生成可读报告”上。

- 输入：代码里写好的股票小数据表。
- 处理：循环、下标、`if`、`append()`、`format()`。
- 输出：先打印报告，再只保留下跌报告，最后写出 `report.txt`。
- 课堂重点：程序不只是算数字，也能筛选信息、组织文字、生成报告。

## 章节页

`#1 从数据到报告`

How to turn data into a report?

L2 已经能批量计算；L3 让结果变成给人看的文字。

## 前置知识：代码里的小数据表

这节课先不读外部文件。直接把几只股票写在代码里：

```python
stocks = [
    ["贵州茅台", "白酒", 1709, 1705],
    ["五粮液", "白酒", 150, 153],
    ["宁德时代", "新能源", 180, 174],
    ["比亚迪", "新能源", 210, 214],
    ["隆基绿能", "新能源", 18, 17.2],
]
```

这是一张很小的表：

- 外层 `stocks` 是一个 list。
- 里面每一行也是一个 list。
- 每一行的顺序固定：股票名称、行业、开盘价、收盘价。

比如第一行：

```python
stock = ["贵州茅台", "白酒", 1709, 1705]

name = stock[0]
industry = stock[1]
open_price = stock[2]
close_price = stock[3]
```

## 主例子：从股票数据到风险报告

这个动手例子分三步走。第一步完整写出来，后面两步都在第一步基础上小改。

### 第一步目标：给每只股票生成一句简报

把每只股票从一行数据，变成一句人能读懂的简报。

- 原始数据：`["贵州茅台", "白酒", 1709, 1705]`
- 程序加工：算涨跌额、涨跌幅
- 输出文字：`贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。`

### 前置知识：报告模板

```python
template = "{}（{}）今日{} {} 元，{} {}%。"
```

这句话里有 6 个 `{}`，后面就要放 6 个值。

### 第一步代码

```python
stocks = [
    ["贵州茅台", "白酒", 1709, 1705],
    ["五粮液", "白酒", 150, 153],
    ["宁德时代", "新能源", 180, 174],
    ["比亚迪", "新能源", 210, 214],
    ["隆基绿能", "新能源", 18, 17.2],
]

for stock in stocks:
    name = stock[0]
    industry = stock[1]
    open_price = stock[2]
    close_price = stock[3]

    change = round(close_price - open_price, 2)
    percent = round(change / open_price * 100, 2)

    if change > 0:
        direction = "上涨"
        change_text = change
        percent_name = "涨幅"
        percent_text = percent
    else:
        direction = "下跌"
        change_text = 0 - change
        percent_name = "跌幅"
        percent_text = 0 - percent

    template = "{}（{}）今日{} {} 元，{} {}%。"
    report = template.format(
        name, industry, direction, change_text, percent_name, percent_text
    )
    print(report)
```

### 第一步标准输出

```text
贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。
五粮液（白酒）今日上涨 3 元，涨幅 2.0%。
宁德时代（新能源）今日下跌 6 元，跌幅 3.33%。
比亚迪（新能源）今日上涨 4 元，涨幅 1.9%。
隆基绿能（新能源）今日下跌 0.8 元，跌幅 4.44%。
```

### 所以呢

- L2 的输出更像“程序结果”。
- L3 的输出开始像“给人看的报告”。
- 同样是数字，换一种表达方式，读者的理解成本会低很多。
- 这里没有用新函数，只是在 `if` 里面准备更适合展示的文字。

## 第二步：只保留下跌股票

### 目标

报告不是把所有内容都倒出来。  
如果这份报告的目标是提醒风险，那就只保留下跌股票。

### 前置知识：append()

```python
risk_reports = []

risk_reports.append("贵州茅台下跌")
risk_reports.append("宁德时代下跌")

print(risk_reports)
```

输出：

```text
['贵州茅台下跌', '宁德时代下跌']
```

`append()` 的意思是：把一条新内容放进 list 的最后。

### 第二步代码

```python
stocks = [
    ["贵州茅台", "白酒", 1709, 1705],
    ["五粮液", "白酒", 150, 153],
    ["宁德时代", "新能源", 180, 174],
    ["比亚迪", "新能源", 210, 214],
    ["隆基绿能", "新能源", 18, 17.2],
]

risk_reports = []

for stock in stocks:
    name = stock[0]
    industry = stock[1]
    open_price = stock[2]
    close_price = stock[3]

    change = round(close_price - open_price, 2)
    percent = round(change / open_price * 100, 2)

    if change < 0:
        down_change = 0 - change
        down_percent = 0 - percent
        template = "{}（{}）今日下跌 {} 元，跌幅 {}%。"
        report = template.format(name, industry, down_change, down_percent)
        risk_reports.append(report)

for report in risk_reports:
    print(report)
```

### 第二步标准输出

```text
贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。
宁德时代（新能源）今日下跌 6 元，跌幅 3.33%。
隆基绿能（新能源）今日下跌 0.8 元，跌幅 4.44%。
```

### 所以呢

- 筛选不是偷懒，是根据问题选择信息。
- 如果目标是风险提示，上涨股票可以先不显示。
- 程序的价值不只是“算”，还包括“帮人筛掉不相关信息”。

## 第三步：把风险提示写入 report.txt

### 目标

前两个例子都是打印在屏幕上。  
这次让程序生成一个文件：`report.txt`。

这个文件不需要提前准备，程序会自己创建。

### 前置知识：写文件

```python
file = open("report.txt", "w", encoding="utf-8")
file.writelines(risk_reports)
file.close()
```

- `"w"` 表示写入。
- 如果 `report.txt` 不存在，程序会创建它。
- 如果 `report.txt` 已经存在，旧内容会被清空。
- `writelines()` 会把 list 里的每一条文字写进去。

### 第三步代码

```python
stocks = [
    ["贵州茅台", "白酒", 1709, 1705],
    ["五粮液", "白酒", 150, 153],
    ["宁德时代", "新能源", 180, 174],
    ["比亚迪", "新能源", 210, 214],
    ["隆基绿能", "新能源", 18, 17.2],
]

risk_reports = []

for stock in stocks:
    name = stock[0]
    industry = stock[1]
    open_price = stock[2]
    close_price = stock[3]

    change = round(close_price - open_price, 2)
    percent = round(change / open_price * 100, 2)

    if change < 0:
        down_change = 0 - change
        down_percent = 0 - percent
        template = "{}（{}）今日下跌 {} 元，跌幅 {}%。\n"
        report = template.format(name, industry, down_change, down_percent)
        risk_reports.append(report)

file = open("report.txt", "w", encoding="utf-8")
file.writelines(risk_reports)
file.close()
```

### 运行后得到的 `report.txt`

```text
贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。
宁德时代（新能源）今日下跌 6 元，跌幅 3.33%。
隆基绿能（新能源）今日下跌 0.8 元，跌幅 4.44%。
```

### 所以呢

- 屏幕输出是临时看的。
- 文件输出是可以留下来、转发、继续加工的。
- `\n` 很重要：没有它，几条报告会挤在同一行。
- 这一步开始，程序就不只是“算给自己看”，而是在生成一个交付物。

## 后半案例 1：数据从哪里来

### 目标

前半的小股票表是我们手写在代码里的。真实工作里，数据通常不会这么乖。

这一段只解决一个问题：

```text
要生成报告，第一步不是写公式，而是先找到数据来源。
```

### 四种入口

```text
手工输入
适合小数据、课堂练习、临时验证。

文件读取
适合 Excel、CSV、txt 这类已经整理好的数据。

API
系统专门留给程序的数据入口。

爬虫
网页本来给人看，程序去页面里把数据抠出来。
```

### 课堂问题

- 今天前半的小股票表，属于哪一种？
- L2 读 `stocks.txt`，属于哪一种？
- 股票软件、天气软件、地图软件，背后更像哪一种？
- 如果网页改版，API 和爬虫哪个更容易坏？

### 所以呢

- 手工输入最容易理解，但不适合大量数据。
- 文件读取适合已经整理过的数据。
- API 通常比爬虫更稳定，因为它本来就是给程序读的。
- 爬虫不是不能用，但不是第一选择。

## 后半案例 2：API 返回什么

### 目标

前半一直用 list：`stock[0]`、`stock[1]`、`stock[2]`。

API 返回的数据，常常更像 dict。这个例子只解决一个问题：

```text
字段很多时，按名字取值比按位置取值更清楚。
```

### 先看 list

```python
stock_list = ["贵州茅台", "白酒", 1709, 1705]

print(stock_list[0])
print(stock_list[3])
```

问题：

- `stock_list[0]` 是什么？
- `stock_list[3]` 是什么？
- 如果这行数据有 20 个字段，还能靠记位置吗？

### 再看 dict

```python
stock_dict = {
    "name": "贵州茅台",
    "industry": "白酒",
    "open": 1709,
    "close": 1705,
}

print(stock_dict["name"])
print(stock_dict["close"])
```

### `[]` 和 `get()`

```python
print(stock_dict["close"])
print(stock_dict.get("price", "没有这个字段"))
```

- `[]`：确定字段存在时直接取，写错就报错。
- `get()`：字段可能不存在时更安全，可以给默认值。

### 所以呢

- list 靠位置，dict 靠名字。
- 真实数据字段多时，dict 更像“有表头的一行数据”。
- API 返回结构化数据时，先认字段，再做计算。

## 后半案例 3：同一份数据，写成不同报告

### 目标

前半已经能生成风险提示：只保留下跌股票。

但报告不是只有一种写法。同一份数据，给不同人看，重点不一样。

### 原始数据

```text
贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。
宁德时代（新能源）今日下跌 6 元，跌幅 3.33%。
隆基绿能（新能源）今日下跌 0.8 元，跌幅 4.44%。
```

### 版本 1：给自己检查

```text
贵州茅台 -4 -0.23%
宁德时代 -6 -3.33%
隆基绿能 -0.8 -4.44%
```

特点：短、直接，适合确认程序有没有跑通。

### 版本 2：给同事看

```text
今日下跌股票共 3 只，其中宁德时代每股下跌金额最大，隆基绿能跌幅最大。
```

特点：开始有归纳，不只搬运数字。

### 版本 3：给领导看

```text
本批样本中，下跌股票主要集中在新能源相关标的。需要注意：样本只有 5 只股票，不能代表整个市场。
```

特点：更短，但必须说明样本范围。

### 课堂问题

- 哪个版本最适合自己调试程序？
- 哪个版本最适合发到工作群？
- 哪个版本最容易误导人？
- 如果说“新能源整体偏弱”，样本够不够？

### 所以呢

- 报告不是把数字倒出来，而是围绕读者组织信息。
- 报告越短，越要说明范围。
- 样本只有 5 只股票，就不能说“整个市场怎么样”。

## 后半案例 4：AI 能帮报告做什么

### 目标

AI 不是用来替你背语法，也不是直接替你下结论。这里让 AI 做一件适合它的事：把程序输出改成更像人能读的观察。

### 不好的问法

```text
帮我分析一下这些股票。
```

问题：太空。AI 容易把小样本说成大市场，也容易编造原因。

### 更好的问法

```text
下面是程序生成的下跌股票报告：

贵州茅台（白酒）今日下跌 4 元，跌幅 0.23%。
宁德时代（新能源）今日下跌 6 元，跌幅 3.33%。
隆基绿能（新能源）今日下跌 0.8 元，跌幅 4.44%。

请根据这几条数据写一段简短观察。
要求：
1. 只讨论这几只股票，不要扩展到整个市场
2. 区分“跌的钱最多”和“跌幅最大”
3. 不要写买卖建议
4. 不要编造下跌原因
5. 最后说明样本很小，结论有限
```

### 参考输出

```text
这几只下跌股票里，宁德时代每股下跌金额最大，跌 6 元；隆基绿能跌幅最大，跌幅为 4.44%。

从行业看，两只新能源相关股票都出现在下跌列表中，但样本只有 5 只股票，不能据此判断整个新能源板块表现。

这段结果适合作为小样本观察，不适合作为投资建议。
```

### 一起检查 AI

- 有没有把“这几只股票”说成“整个市场”？
- 有没有把跌幅最大说成最值得买或最危险？
- 有没有编造政策、新闻、资金流原因？
- 有没有区分跌的钱最多和跌幅最大？

### 所以呢

- AI 很适合把程序输出改成人能读的文字。
- 给 AI 的边界越清楚，输出越容易检查。
- 真正重要的不是“让 AI 说”，而是知道它哪里可能说过头。

## 后半收束：几个真正有用的数据分析词

### 口径：你到底在算什么？

前半代码用的是开盘价和收盘价：

```python
change = close_price - open_price
percent = change / open_price * 100
```

这表示：从开盘到收盘，价格变化了多少。  
它不是股票软件里最常见的“相对昨日收盘价”的涨跌幅。

同样叫“今天涨跌”，口径不同，数字就可能不同。

### 样本：你看的是全部，还是一小部分？

```text
前半只有 5 只股票。
```

这只能说“这 5 只股票里发生了什么”。  
如果要说“今天 A 股怎么样”，需要更大的数据范围。

### 金额：每股少了多少钱

```text
宁德时代跌 6 元，跌的钱最多。
```

按金额看，关注的是每一股多了或少了多少钱。

### 比例：相对原价跌了多少

```text
隆基绿能跌 4.44%，跌幅最大。
```

按比例看，关注的是相对原价变化了多少。

### L3 Recap

- list 里可以放 list，用来表示一张小表。
- `for` 可以逐行处理这张小表。
- `format()` 可以把数据组织成自然语言。
- `append()` 可以先把需要的报告收集起来。
- `writelines()` 可以把报告写成文件。
- 报告不是把所有数字倒出来，而是围绕问题和读者组织信息。
- API 是程序获取数据的一种常见入口，通常比爬虫更适合稳定读取结构化数据。
- AI 可以帮忙改写和分析，但要用数据范围、口径和样本约束它。
