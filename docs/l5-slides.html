#1 从历史数据到报告

Use pandas to make a report

L4 只保存了一行汇总；L5 开始处理一整段历史数据。

目标

这节课只围绕一个函数

def make_history_excel(file_name):
    ...
输入一份疫情 JSON 数据。
输出l5_report.xlsx 和 l5_trend.png。
主线读数据，整理表格，生成报告。

历史数据

每一行，是一天的记录

{
    "date": "10.05",
    "certain": "35270206",
    "die": "1036359",
    "recure": "26340847"
}

字段

date 日期，certain 累计确诊，die 累计死亡，recure 累计治愈。

注意

数字外面有引号，刚读出来时很可能还是字符串。

第一步

读 JSON，变成 DataFrame

打开文件读取本地疫情 JSON。
找到列表data -> otherhistorylist。
变成表只保留日期、累计确诊、死亡、治愈。

第一步 Recap

DataFrame 看起来像 Excel

  • json.load(file) 把 JSON 文件读成 Python 里的 dict / list。
  • otherhistorylist 是一批历史记录。
  • pd.DataFrame(...) 把一批记录变成一张表。
  • columns=[...] 只保留本节课要用的列。

第二步

重命名，转换类型

重命名

date、certain 这些字段来自数据源，不适合直接给人看。

转数字

从 JSON 读出来的数字，很多时候先是文字；计算前要确认类型。

第二步 Recap

真实数据不能急着算

  • rename() 让表头更适合人读。
  • astype() 把列转换成指定类型。
  • 字段名清楚，后面的代码才不容易写错。
  • 类型正确，除法、求和、画图才稳定。

第三步

新增指标，导出报告

新增列死亡率 = 累计死亡 / 累计确诊 * 100。
Excel保存整理后的明细表。
趋势图画累计确诊随日期变化的曲线。

第三步 Recap

生成的是一份报告

  • df["死亡率"] = ... 给表新增一列。
  • to_excel(...) 把整理后的表交付出去。
  • df.plot(...) 把表里的数字变成趋势图。
  • Excel 适合查具体数字，图适合看变化。

一条完整的数据工作流

JSON 文件里是一批历史记录；pandas 把它整理成表；类型正确后才能稳定计算；Excel 和趋势图负责交付结果。

1. 表和图

Excel 适合查细节，趋势图适合看一段时间的形状。

案例 2

人数更多，风险就一定更高吗？

同一组数据，用“人数”看一次，再用“比例”看一次，结论可能会变。

案例 2 · 数据

两个地区，规模不一样

地区累计确诊累计死亡死亡率
地区 A10000030003%
地区 B100005005%

A 的总量更大，B 的比例更高。先别急着说谁“更严重”，要看你在问哪一种严重。

案例 2 · 问题

这两个判断，分别在问什么？

  • 如果医院要准备床位和物资，更应该先看死亡人数，还是死亡率？
  • 如果想比较两个地区的严重程度，更应该先看死亡人数，还是死亡率？
  • 为什么“总量”和“比例”都对，但不能混在一起说？

案例 2 · 所以呢

绝对数看总量，比例看压力

  • 只看死亡人数，注意力会自然落到大地区，因为它的确诊基数本来就大。
  • 死亡率把确诊规模也算进去，能提醒我们：总人数不大，不代表压力一定小。
  • 这和 L1 的股票例子是同一件事：跌了多少钱看损失金额，跌了百分之多少才方便比较严重程度。

案例 3

累计一直上升，不等于速度一直变快

累计图很重要，但它不是全部答案。要看速度，就要引入“新增”。

案例 3 · 概念

累计数像总收入，新增数像今天收入

今天收入 10 万，累计收入上升。
明天只收入 2 万，累计收入还是上升。
变化总收入继续增加，但增长速度已经变慢。

案例 3 · 问题

看累计图时，容易错过什么？

  • 如果累计确诊还在上升，新增速度可能已经变慢吗？
  • 如果每日新增开始下降，累计确诊会不会马上下降？
  • 为什么只看累计图，可能错过变化速度？

案例 3 · 所以呢

总量和速度，要分开看

累计数

告诉你现在一共累积到多少。只要还有新增，它通常就会继续往上。

新增数

告诉你变化速度是在加快还是放慢。它比累计数更敏感。

L7 会正式解决：怎么把今天和昨天放到一起比较。

“累计确诊还在上升，但每日新增下降了”
这句话怎么用普通人能听懂的方式解释？

要求：不要解释原因，只解释“累计”和“新增”的区别。

AI 参考输出 · 案例 3

可以接受的回答，大概长这样

这句话的意思是：
总量还在增加，但增加速度变慢了。

比如累计收入还在上涨，
但今天新增收入比昨天少，
说明业务还在增长，只是增长没那么快了。

所以“累计上升”和“新增下降”并不矛盾。
