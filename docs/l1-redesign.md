### 例子 1：圆面积

```python
def get_round_area(r):
    pi = 3.14
    area = pi * r ** 2
    return area

r = input("input r pls: ")
result = get_round_area(r)

print(result)
```

讲解重点：

- `get_round_area` 是函数名称，意思是“计算圆的面积”。
- `r` 是参数，也是半径；这是参数的第一次重点应用。
- `get_round_area(5)` 表示把半径 `5` 传给函数。
- `pi`、`area`、`result` 都是变量。
- `pi = 3.14` 是在函数里面定义圆周率。
- 数学公式可以翻译成代码。
- `*` 是乘法， `**` 是n次方。
- `area = pi * r ** 2` 是把圆面积公式翻译成代码。
- `return area` 是把面积作为函数结果输出。
- `print(result)` 是把函数输出显示出来。`input(‘xxx’)`是获得用户的输入
- 数字和字符串的区别 小例子 1 + 1 VS ‘1’ + ’1'

### 例子 2：判断奇偶数

```python
def odd_or_even(number):
    if number % 2 == 0:
        return "even"
    else:
        return "odd"

number = input('pls input a number: ')
result = odd_or_even(number)

print(result)
```

讲解重点：

- `odd_or_even` 是函数名称，意思是“判断奇数还是偶数”。
- `number` 是参数，是传进函数的数字。
- `if` 是流程控制：如果条件成立，就走下面缩进的代码。
- `%` 是求模，也就是求余数。
- `number % 2 == 0` 表示“这个数字除以 2 的余数是不是 0”。
- `==` 是判断两边是否相等，不是赋值。和 `=` 的区别
- `else` 表示前面的条件不成立时走这里。
- `return "even"` 和 `return "odd"` 是函数输出。

### 概念页：流程控制

- Flow Control：让程序根据条件走不同路线。
- 条件成立：走 `if` 下面的代码。
- 条件不成立：走 `else` 下面的代码。

### 流程图：奇偶数

### 后半例子 1：涨跌额 vs 涨跌幅

#### 代码页

```python
stock_name = "贵州茅台"

yesterday = 1709.00
today = 1705.00

price_change = today - yesterday
percent_change = price_change / yesterday * 100

print(stock_name)
print("涨跌金额：", price_change)
print("涨跌幅：", percent_change, "%")
```

#### 标准输出：

```text
贵州茅台
涨跌金额： -4.0
涨跌幅： -0.23405500292568755 %
```
- 这里先不处理小数太长的问题，后续再讲保留两位小数。
  
#### 口头技术识别

- 哪些是变量？
- 哪一行把股票名字放进了变量？
- `today - yesterday` 算的是什么？
- `percent_change = price_change / yesterday * 100` 右边做了几步计算？
- 这段代码最后会打印几行？

#### 猜一下

- 跌了 4 元，算多吗？

#### 加条件

- 如果一只 40 元股票跌了 4 元呢？
- 如果一只 1709 元股票跌了 4 元呢？

#### 继续追问

- 这时候你更想看“跌了多少钱”，还是“跌了百分之多少”？
- 为什么股票里经常说“涨跌幅”，而不是只说“涨跌金额”？

#### 答案页

- 跌 4 元本身不能说明严重不严重，要看原价是多少。
- 如果一只 40 元股票跌 4 元，那是跌 10%；如果贵州茅台从 1709 跌 4 元，只是大约跌 0.23%。
- 同样跌 4 元，前者是明显波动，后者更像轻微变化。
- 买菜也一样：白菜 2 元/斤，涨 5 毛是涨 25%；排骨 30 元/斤，涨 1 元只是涨 3.33%。排骨涨的钱更多，但白菜涨得更厉害。
- 所以看价格变化，不能只看“差了多少钱”，还要看这个变化占原价的多少。

#### 数据分析知识点：

- 涨跌额是绝对变化：今天价格 - 昨天价格。
- 涨跌幅是相对变化：涨跌额 / 昨天价格 * 100。
- 不同基数的数据，不能只看差值，还要看比例。
- 涨跌额回答“变了多少钱”，涨跌幅回答“变化占原来多少比例”。


公式：

```text
涨跌幅 = 涨跌金额 / 昨日价格 × 100%
```

### 后半例子 2：同样投入 10000 元，涨了一块钱，谁赚得更多

#### 代码页

```python
stock_a = "股票A"
a_buy  = 10

stock_b = "股票B"
b_buy = 40

money = 10000
price_change = 1

a_shares = int(money / a_buy / 100) * 100
b_shares = int(money / b_buy / 100) * 100

a_percent = price_change / a_buy * 100
b_percent = price_change / b_buy * 100

a_profit = price_change * a_shares
b_profit = price_change * b_shares

if a_profit > b_profit:
    better_stock = stock_a
else:
    better_stock = stock_b

print(stock_a, "涨幅", a_percent, "%", "赚了", a_profit, "元")
print(stock_b, "涨幅", b_percent, "%", "赚了", b_profit, "元")
print("赚得更多的是：", better_stock)
```

#### 标准输出：

```text
股票A 涨幅 10.0 % 赚了 1000 元
股票B 涨幅 2.5 % 赚了 200 元
赚得更多的是： 股票A
```

#### 口头技术识别

- 股票 A 和股票 B 分别用了哪些变量？
- `money` 表示什么？
- `price_change` 表示什么？
- `a_shares` 和 `b_shares` 分别表示什么？
- `a_percent` 和 `b_percent` 分别表示什么？
- `int(money / b_buy / 100) * 100` 这一行在做什么？
- 为什么股票 B 理论上可以买 250 股，实际这里只写 200 股？
- `if a_profit > b_profit` 在判断什么？
- 最后会打印几行？

#### 加条件

- 股票 A 价格 10 元，股票 B 价格 40 元。
- A 股通常 100 股一手，不能随便买 250 股。

#### 继续追问

- 股票 A 涨了 1 元，股票 B 也涨了 1 元，为什么股票 A 赚了 1000 元，股票 B 只赚了 200 元？
- 看起来都是“涨 1 元”，为什么最后能差到 5 倍？
- 这里到底是买入价格、买入股数、涨幅，哪一个改变了结果？

#### 答案页

- 股票 A 从 10 元涨到 11 元，每股涨 1 元，涨幅是 10%；10000 元可以买 1000 股，所以赚 1000 元。
- 股票 B 从 40 元涨到 41 元，每股也涨 1 元，涨幅是 2.5%；10000 元理论上可以买 250 股，但 A 股通常 100 股一手，所以这里按 200 股计算，赚 200 元。
- 看起来两只股票都涨 1 元，但买入价格、可买股数、涨幅都不一样，最后收益差了 5 倍。
- 这里最容易被小学除法骗：`10000 / 40 = 250` 没错，但真实交易不是想买 250 股就能买 250 股。
- 所以数据分析要把业务规则放进来。规则没放进去，算得再准也可能不是现实里的结果。

#### 数据分析知识点：

- 同样投入 10000 元，价格 10 元可以买 1000 股，价格 40 元按整手只能买 200 股。
- 两只股票都涨 1 元时，买入价格越低，涨幅越高，真实能买到的股数也通常更多；这个差距会直接影响收益。
- 比较投资表现时，投入金额、持有数量和涨幅要一起看。
- 数据分析不是把数字直接套公式；先要确认业务规则，比如 A 股买入通常按 100 股一手。

公式：

```text
理论股数 = 投入金额 / 买入价格
真实 A 股买入股数 = 能买到的整手数量 × 100
收益金额 = 每股涨跌金额 × 持有股数
```

#### 改参数

- 如果股票 B 是 25 元，10000 元能买多少股？
- 如果投入变成 20000 元，谁赚得更多？
- 如果两只股票都是涨 10%，谁赚得更多？

#### 改参数答案

- B 是 25 元时，10000 元可以买 400 股。
- 投入 20000 元时，A 买 2000 股赚 2000 元，B 买 500 股赚 500 元。
- 如果两只股票都涨 10%，同样投入 10000 元，收益接近投入的 10%。

### 后半例子 3：跌 50% 后再涨 50%，回本了吗

#### 代码页

```python
stock_name = "练习股票"

start_price = 100
after_drop = start_price * 0.5
after_rise = after_drop * 1.5

if after_rise >= start_price:
    result = "回本了"
else:
    result = "还没回本"

print(stock_name)
print("一开始价格：", start_price)
print("下跌50%后：", after_drop)
print("再上涨50%后：", after_rise)
print(result)
```

#### 标准输出：

```text
练习股票
一开始价格： 100
下跌50%后： 50.0
再上涨50%后： 75.0
还没回本
```

#### 口头技术识别

- `after_drop` 是从哪个价格算出来的？
- `after_rise` 是从哪个价格继续涨？
- `if after_rise >= start_price` 在判断什么？
- 最后会打印几行？

#### 追问

- 为什么不是 100？
- 从 50 回到 100，到底要涨多少才算回本？

#### 答案页

- 先跌 50%，再涨 50%，最后不是 100，而是 75。
- 第一次下跌：100 × 0.5 = 50。
- 第二次上涨：50 × 1.5 = 75。
- 因为 75 小于 100，所以程序输出“还没回本”。
- 跌 50% 要涨 100% 才回本。

#### 数据分析知识点：

- 百分比每次都基于“当下的基数”计算。
- 跌 50% 后，基数从 100 变成 50；再涨 50%，是在 50 的基础上多 25，所以只能到 75。
- 这就是为什么回撤容易、回本难：跌得越多，后面需要的涨幅会越来越夸张。
- 商品先五折再涨价五折，不会回到原价；工资从 10000 降到 8000，再涨回 10000，需要涨 25%，不是 20%。
- 所以连续百分比变化不能简单相加，要按顺序一步步算。

公式：

```text
涨跌金额 = 当前基数 × 涨跌幅
从 50 回到 100 的涨幅 = (100 - 50) / 50 × 100% = 100%
```

#### 回本小表

```text
跌 10%，需要涨约 11.1% 回本
跌 20%，需要涨 25% 回本
跌 50%，需要涨 100% 回本
```
